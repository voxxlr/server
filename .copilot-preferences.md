# Copilot Preferences

## Code Style

- Do not add comments to code
- Do not add JSDoc comments
- Do not add inline comments
- Do not add TODO comments
- Keep code clean and self-documenting

### Functions
- Do not create wrapper functions that are called only once - inline the code directly
- Only extract code into a function when it is:
  - Called multiple times
  - Recursive
  - Passed as a callback
  - Significantly improves readability of complex logic

## General

- Use Tailwind CSS for styling
- Use Lit for web components
- Components include `/styles-built.css` via link tag in render()
- Import Lit from CDN: `https://cdn.jsdelivr.net/npm/lit@3/+esm`

## Session Management

- When asked to "summarize the conversation", update `.copilot_summary.md` with the current session state
- Read `.copilot_summary.md` at the start of new sessions to understand prior context
