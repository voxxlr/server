# Copilot Preferences

## Code Style

- Do not add comments to code
- Do not add JSDoc comments
- Do not add inline comments
- Do not add TODO comments
- Keep code clean and self-documenting

## General

- Use Tailwind CSS for styling
- Use Lit for web components
- Components include `/styles-built.css` via link tag in render()
- Import Lit from CDN: `https://cdn.jsdelivr.net/npm/lit@3/+esm`
