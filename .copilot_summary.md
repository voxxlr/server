# Copilot Session Summary

## Project Overview
Voxxlr is a cloud platform for GIS and BIM data - web-based visualization and analysis tools for point clouds, 3D models, drone maps, and 360 images.

### Architecture
Three subdomains, each an Express server:
- **www.voxxlr.com** (port 80) - Marketing/landing page with login
- **app.voxxlr.com** (port 3022) - Application launchpad with 10+ apps
- **doc.voxxlr.com** (port 3021) - Document/dataset API and 3D/2D viewer

## Current Work: Porting /www to Cloud Functions

### Completed Changes

#### 1. Stack Decisions (PLAN.md updated)
- **Using:** Tailwind CSS, Lit (web components), Cloud Functions
- **Removed from plan:** Vite, Alpine.js

#### 2. Server Configuration
- Changed host from `0.0.0.0` to `localhost` in all servers
- Updated `.env` to use `localhost` instead of `127.0.0.1`

#### 3. Cloud Functions Setup
- Added `exports.www = app` to server.js for Cloud Functions
- Created `deploy.js` script that:
  - Copies `_platform/gce` to local `platform/` folder
  - Deploys via `gcloud functions deploy`
  - Auto-cleans up platform folder after deploy
- Removed Functions Framework (not needed - plain Express works fine locally)

#### 4. Directory Restructure
**Before:**
```
www/
├── client/          ← Static files
│   ├── index.html
│   └── components/
└── server/          ← Express server
    └── server.js
```

**After:**
```
www/
├── server.js        ← Entry point (exports.www for Cloud Functions)
├── deploy.js        ← Deployment script
├── package.json
├── Dockerfile
├── routes/          ← All content here
│   ├── index.js     ← Route handlers
│   ├── login.js
│   ├── common.js
│   ├── index.html   ← HTML templates (Mustache)
│   ├── login.html
│   ├── main.html
│   ├── components/  ← Lit web components
│   │   ├── va-login.js
│   │   └── vx-modal.js
│   ├── images/
│   ├── styles.css
│   ├── styles-built.css
│   └── favicon.ico
└── platform/        ← Auto-generated at deploy time (gitignored)
```

#### 5. Updated Paths
- `.vscode/launch.json` - www server now at `www/server.js`
- `server.js` - platform path changed to `../_platform/gce`
- `server.js` - static files served from `./routes`
- `package.json` - `#common` import points to `./routes/common.js`
- `routes/index.js` - HTML files loaded via `path.join(__dirname, 'file.html')`

### Key Files
- `server.js` - Loads platform APIs, sets up routes, exports for Cloud Functions
- `deploy.js` - Run `npm run deploy` to deploy to GCP
- `routes/index.js` - Handles `/`, `/index.html`, `/main.html`, `/login.html`
- `routes/login.js` - Handles OAuth (`/login/google`, `/login/noauth`)

### Important Notes
- `key.json` files are auto-generated at runtime from `GCLOUD_KEY` env var (gitignored)
- Mustache templating injects `{{{variables}}}` into HTML at request time
- Platform modules (`_platform/gce/*`) are copied into `platform/` only during deploy

### Commands
```bash
cd www
npm start         # Run locally
npm run deploy    # Copy platform + deploy to GCP + cleanup
```

### Cloud Functions URL Pattern
```
https://REGION-PROJECT_ID.cloudfunctions.net/www/
https://REGION-PROJECT_ID.cloudfunctions.net/www/main.html?account=...
```
